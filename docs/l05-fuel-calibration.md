## Lab：火星基地燃料校准实验

从空文件创建 `src/L05/fuel_calibration.c`。程序读取一行中的三个整数：

```text
<fuel> <boost> <reserve>
```

三个输入都必须在 `0` 到 `100` 之间。输入数量或格式不正确时，输出明确错误信息并以非零状态结束；数值超出范围时同样处理。

程序必须包含下列三类自定义函数：

- 一个 `void` 函数模拟加注：它接收燃料和加注量，在函数内部将燃料增加后输出模拟结果。
- 一个返回 `int` 的函数计算加注后的燃料值。
- 一个返回 `int` 的函数判断校准后燃料是否不少于最低储备；用 `0` 或非零值表示结果。

在 `main` 前写出这三个函数的原型，在 `main` 后给出函数定义。`main` 必须使用 `int main(void)`，成功结束时返回 `0`。

输出中必须出现以下稳定标签：

```text
FUEL_BEFORE
SIMULATED_FUEL
FUEL_AFTER_SIMULATION
CALIBRATED_FUEL
HELPER_STATUS
MAIN_STATUS
```

`FUEL_AFTER_SIMULATION` 必须仍是调用模拟函数前的燃料值。随后，`main` 接收“计算加注后燃料”函数的返回值，并以 `CALIBRATED_FUEL` 输出该值。

`main` 和“判断储备”函数都要声明名为 `status` 的局部变量。判断函数输出自己的 `HELPER_STATUS`，`main` 用接收到的结果输出自己的 `MAIN_STATUS`。不要使用全局变量、数组、循环、指针、结构体、动态内存、文件读写或 `goto`。

## 在 VS Code 中运行与调试

使用 **Run Code** 运行程序，在 Code Runner 的终端中依次输入测试数据。确认运行输出和编译信息中没有警告。

至少验证以下情况：

| 输入 | 必须观察到的结果 |
| --- | --- |
| `50 20 30` | 模拟燃料为 `70`，模拟后主程序燃料仍为 `50`，校准燃料为 `70`，储备足够 |
| `12 5 30` | 模拟后主程序燃料仍为 `12`，校准燃料为 `17`，储备不足 |
| `0 0 0` | 校准燃料为 `0`，储备足够 |
| `120 1 1` | 范围错误且非零结束 |
| `abc` | 格式错误且非零结束 |

再使用调试器完成一次观察：在模拟加注函数中设置断点，观察函数内燃料改变；返回 `main` 后确认调用者的燃料未变。接着进入返回加注后燃料的函数，观察返回值被赋给 `main` 中的校准燃料变量。最后观察两个作用域中的 `status`。
