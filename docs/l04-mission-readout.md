## Lab：火星基地任务读数分析

从空文件创建 `src/L04/mission_readout.c`。程序读取一行中的三个整数：

```text
<distance_km> <cargo_kg> <signal>
```

三个输入都必须在 `0` 到 `100` 之间。输入数量或格式不正确时，输出明确错误信息并以非零状态结束；数值超出范围时同样处理。

把任务读数拆成三个**有返回值**的自定义函数：

- 一个函数根据距离和载荷计算能耗；规则固定为 `distance * 4 + cargo * 2`。
- 一个函数根据能耗和信号判断任务是否就绪；能耗不超过 `500` 且信号不少于 `60` 时为就绪。
- 一个函数给出单个字符的任务等级：信号不少于 `85` 且能耗不超过 `150` 时为 `S`；其余就绪任务为 `A`；未就绪任务为 `C`。

函数定义必须放在 `main` 前，`main` 负责读取输入、调用函数并组合输出。本任务不使用函数原型；这是下一项任务的内容。

输出中必须包含原始读数，并使用以下稳定标签：

```text
ENERGY
READY
GRADE
```

`READY` 的值使用 `0` 或非零值表达。不要把计算、就绪判断和等级判断全部堆在 `main` 中，也不要为了凑函数数量而让函数只打印固定文本。

只使用目前已学过的输入输出、表达式、条件判断和函数。不使用数组、循环、指针、全局变量、结构体、动态内存、文件读写或 `goto`。

## 在 VS Code 中运行与调试

使用 **Run Code** 运行程序，在 Code Runner 的终端中依次输入测试数据。确认运行输出和编译信息中没有警告。

至少验证以下情况：

| 输入 | 必须观察到的结果 |
| --- | --- |
| `20 10 90` | 能耗为 `100`，就绪，等级为 `S` |
| `80 80 70` | 能耗为 `480`，就绪，等级为 `A` |
| `20 10 40` | 未就绪，等级为 `C` |
| `100 100 80` | 能耗为 `600`，未就绪，等级为 `C` |
| `abc` | 格式错误且非零结束 |

再使用调试器完成一次观察：在 `main` 调用能耗函数的位置设置断点，单步进入函数，观察形参和局部计算结果；继续运行并观察返回值回到 `main` 后被保存和使用。
